Docker

Empaqueta, distribuye y ejecuta aplicaciones en cualquier entorno de forma consistente.

📦 ¿Qué es Docker?

Docker es una plataforma de virtualización a nivel de sistema operativo que permite crear, ejecutar y distribuir aplicaciones dentro de contenedores.

A diferencia de las máquinas virtuales, los contenedores comparten el kernel del sistema operativo host, lo que los hace mucho más ligeros, rápidos y eficientes en recursos.

🏗️ Contenedores

Un contenedor es una instancia en ejecución de una imagen Docker. Es el proceso aislado que contiene todo lo necesario para ejecutar una aplicación:

Su propio sistema de archivos, stack de red, variables de entorno y proceso principal. Los contenedores son efímeros: se crean, se ejecutan y se destruyen sin dejar datos persistentes a menos que se configuren volumenes.

🖼️ Imágenes y Contenedores

La relación entre imágenes y contenedores es clave:

Una imagen es una plantilla de solo lectura con todo lo necesario para ejecutar una app (código, runtime, configuraciones, dependencias). Un contenedor es una copia ejecutable de esa imagen.

Puedes crear miles de contenedores a partir de una misma imagen, cada uno aislado y con su propio estado.

📝 Dockerfile

Un Dockerfile es un archivo de texto con instrucciones paso a paso para construir una imagen Docker. Cada instrucción crea una capa (layer) en la imagen.

Dockerfile 
# Imagen base
FROM node:20-alpine

# Directorio de trabajo dentro del contenedor
WORKDIR /app

# Copiar archivos de dependencias primero (cache)
COPY package*.json ./

# Instalar dependencias
RUN npm install

# Copiar el resto del código fuente
COPY . .

# Puerto que expone la app
EXPOSE 3000

# Comando de inicio
CMD ["node", "server.js"]

Instrucciones comunes del Dockerfile

▼
FROM Define la imagen base sobre la cual se construye.
RUN Ejecuta comandos durante la construcción (ej: instalar paquetes).
COPY / ADD Copia archivos del host al contenedor.
WORKDIR Establece el directorio de trabajo dentro del contenedor.
EXPOSE Documenta qué puertos usa la aplicación.
CMD / ENTRYPOINT Define el comando que se ejecuta al iniciar el contenedor.
ENV Define variables de entorno.

🔧 Docker Compose

Docker Compose es una herramienta para definir y ejecutar aplicaciones con múltiples contenedores usando un archivo YAML. Ideal para desarrollo local, pruebas y escenarios donde necesitas varios servicios trabajando juntos.

docker-compose.yml 
version: "3.8"

services:
  web:
    build: .
    ports:
      - "3000:3000"
    depends_on:
      - db
    environment:
      DATABASE_URL: postgres://user:pass@db:5432/mydb

  db:
    image: postgres:16-alpine
    volumes:
      - pgdata:/var/lib/postgresql/data
    environment:
      POSTGRES_USER: user
      POSTGRES_PASSWORD: pass
      POSTGRES_DB: mydb

volumes:
  pgdata:

⌨️ Comandos Esenciales

docker run -d --name mi-app -p 8080:80 nginx Crea y ejecuta un contenedor desde la imagen nginx en segundo plano.
docker ps Lista los contenedores en ejecución.
docker ps -a Lista todos los contenedores (incluyendo los detenidos).
docker stop <id|nombre> Detiene un contenedor en ejecución.
docker rm <id|nombre> Elimina un contenedor detenido.
docker exec -it <id> /bin/sh Abre una shell interactiva dentro de un contenedor.
docker logs <id|nombre> Muestra los logs del contenedor.
docker build -t mi-app:1.0 . Construye una imagen desde un Dockerfile.
docker images Lista las imágenes locales.
docker pull <imagen> Descarga una imagen de Docker Hub.
docker push <imagen> Sube una imagen a un registro (Docker Hub, ECR, etc.).
docker rmi <imagen> Elimina una imagen local.
docker tag <imagen> <nuevo-tag> Crea un alias/tag para una imagen.
docker network ls Lista todas las redes disponibles.
docker network create mi-red Crea una red personalizada.
docker network connect mi-red <contenedor> Conecta un contenedor a una red.
docker network disconnect mi-red <contenedor> Desconecta un contenedor de una red.
docker volume create mi-vol Crea un volumen persistente.
docker volume ls Lista los volúmenes disponibles.
docker run -v mi-vol:/data <imagen> Monta un volumen dentro del contenedor.
docker run -v /host/path:/container/path <imagen> Mount directo de una carpeta del host (bind mount).
